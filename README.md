# C++ Time Converter
<br>
A simple C++ program that converts time in seconds into hours, minutes, and seconds.
<br>
Supports both 12-hour (AM/PM) and 24-hour time formats.
<br>
Includes basic input validation and handles midnight and noon correctly.
<br>
Built using fundamental C++ concepts such as `if-else`, `switch-case`, and arithmetic operators.
<br>
Created as a beginner project to practice C++ programming and logical thinking.
